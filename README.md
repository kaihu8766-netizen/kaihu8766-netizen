## 对 AI 的理解

在财务与资金实务中，我把 AI 作为提高效率的协作工具，用于数据清洗、报表与台账自动化、情景模拟及行业资料提炼。

AI 的边界很明确：它不能替代专业判断，更不能承担合规责任；所有 AI 辅助产出的数据，必须设定边界用例人工复核，做到留痕对账、结果可复验。
